# 程序员的自我修养

一个 C/C++ 程序从源代码到真正运行，中间发生了什么？《程序员的自我修养——链接、装载与库》沿着程序的生成与执行过程，讲述目标文件、静态链接、动态链接、程序装载和运行库的工作方式。

[开始阅读](chapters/01/sections/1.1.md){ .primary-link } [浏览全书目录](contents.md){ .secondary-link }

## 顺着程序的生命周期阅读

熟悉 C 语言之后，可以按全书顺序阅读：先回顾硬件、操作系统和线程，再观察目标文件，理解链接器如何组织代码与数据，接着追踪程序装载、共享库和运行库。第 13 章通过 Mini CRT 把这些知识联系起来。

## 边读边验证

理解文件布局时，把书中的图与工具输出放在一起看；阅读链接过程时，跟踪一个符号从定义、引用到地址确定的变化。遇到平台相关的命令与实现，先确认当前阅读的是 Linux 还是 Windows，再比较它们的共同机制。

## 怎样使用本站

点击章名即可进入正文，章名旁的箭头用于展开小节。页底的上一页、下一页按正文顺序连续翻页；“整章阅读”可以把同一章放在一个页面中查看。

顶部搜索可查找 ELF、重定位、GOT、DLL、运行库等术语。图表与代码可以点击放大。顶部按钮可以切换明暗主题，手机上通过左上角菜单打开目录。
